# Product Marketing Context

*Last updated: 2026-03-29*

## Product Overview

**One-liner:** 蕭宇程（Swanky Hsiao）是橫跨得獎攝影、敏捷技術顧問與 Web3 教育的複合型創作者，以 Swanky Studio 史旺基工作室為品牌對外服務。

**What it does:**
Swanky Studio 提供三大核心服務：人像與商業攝影（含制服女孩系列等個人 IP）、企業技術顧問（Java 架構、敏捷、區塊鏈 R&D），以及攝影與加密貨幣教育課程。網站同時作為創辦人個人品牌的展示平台與知識分享媒介。

**Product category:** 個人品牌 / 複合型創作者作品集（Multi-hyphenate creator portfolio）

**Product type:** 個人品牌網站 — 服務型（攝影、顧問、教育），非 SaaS

**Business model:**
- 攝影服務：按件計費（portrait、commercial、活動紀錄）
- 技術顧問：企業案件、區塊鏈 R&D 輔導
- 教育訓練：大學課程（東吳大學）、企業內訓、個人小班
- 演講與工作坊
- Web3 / NFT 專案顧問與共同創辦

## Target Audience

**Target clients:**
1. 攝影委託客戶 — 尋找有國際獎項背書的人像、商業攝影師的個人或品牌
2. 技術與企業合作夥伴 — 需要區塊鏈顧問、敏捷教練或技術領導力的公司
3. 教育機構與企業培訓採購者 — 大學、設計公司、科技公司
4. 攝影愛好者與粉絲 — 追蹤制服女孩系列及 PX3/IPA/TIME 獎項作品的族群
5. 媒體與記者 — 尋找採訪對象、報導 Web3/NFT 或攝影題材

**Decision-makers:** 企業主、企業培訓主管、大學課程規畫者、個人客戶（婚攝、形象攝影）

**Primary use case:** 評估是否委託攝影服務 / 邀請演講顧問 / 報名課程

**Jobs to be done:**
- 找到可信賴、有國際認可的攝影師為品牌或個人拍攝形象照
- 找到同時懂技術又有業界實戰的區塊鏈顧問/講師
- 透過課程快速理解加密貨幣、NFT、Web3 等新興領域

**Use cases:**
- 企業形象/年報攝影委託
- 個人寫真（藝人、模特兒、素人）
- 區塊鏈技術評估與導入規畫
- 大學或企業區塊鏈/Web3 課程規畫
- NFT 發行策略輔導

## Problems & Pain Points

**Core problem:**
客戶很難找到「真正跨域」的專業人士 — 攝影師通常不懂技術，技術顧問通常沒有視覺說服力，Web3 教育者通常缺乏實戰紀錄。

**Why alternatives fall short:**
- 一般攝影師：缺乏國際認可與商業深度
- 一般技術顧問：無跨領域敘事能力，難以讓非技術決策者信服
- 一般 Web3 講師：理論多、自身持有紀錄不透明、缺乏社群建立實績

**What it costs them:**
- 委外攝影踩到地雷 → 品牌形象受損、時間金錢浪費
- 導入錯誤技術顧問 → 開發方向偏差、組織阻力
- 選錯 Web3 課程 → 知識不落地、員工學完仍不知如何應用

**Emotional tension:** 不確定感（這個人值得信任嗎？他說的是真實經驗還是紙上談兵？）

## Competitive Landscape

**Direct (攝影):** 台灣人像商業攝影師 — 多數缺乏國際獎項背書，風格較制式
**Direct (技術顧問):** Java/敏捷顧問公司 — 多為顧問公司體制，缺乏個人品牌信任感
**Direct (Web3 教育):** 幣圈 KOL 課程 — 通常以交易獲利為賣點，非系統性技術/生態系教育

**Indirect:** 不委外，企業自己培養內部人才或自學

**Tertiary (競爭注意力):** 社群媒體 KOL、YouTube 自學資源

## Differentiation

**Key differentiators:**
- 唯一同時擁有 TIME Magazine 登上紀錄 + 區塊鏈研究博士學位背景的創作者
- 親身發行 NFT 並公開記錄完整過程（成功與失敗）
- 制服女孩系列已成為跨越攝影→書籍→NFT→Web3 社群的 IP
- 台灣大哥大現任部級主管，具企業內部視角
- 東吳大學連續 8 年授課，課程設計已驗證

**How we do it differently:** 用攝影師的眼睛說技術故事；用技術人的邏輯組織創作 IP

**Why that's better:** 客戶不只得到服務，還得到一個能跨語言溝通的合作夥伴

**Why customers choose us:** 真實的跨域履歷無法被模仿；豐富的公開內容降低信任成本

## Objections

| Objection | Response |
|-----------|----------|
| 「你很多領域，專精度夠嗎？」 | 每個領域都有具體的國際/機構認可：攝影有 PX3/IPA/TIME，技術有博士+CSM+台哥大資歷，教育有東吳 8 年 |
| 「攝影費用/顧問費會不會很貴？」 | 品質與成本有對應關係；國際得獎作品帶來的品牌價值遠超過服務費用 |
| 「Web3 是不是在炒作泡沫？」 | Swanky 親身跑過 NFT 發行、記錄失敗，關注的是技術應用與社群機制，不推薦純投機 |

**Anti-persona:** 只想要最便宜攝影師的預算導向客戶；尋找快速致富秘訣的幣圈投機者；需要大型顧問公司規模交付的企業

## Switching Dynamics

**Push (離開現有方案的驅力):**
- 用過普通攝影師結果不滿意
- 企業內訓找到了理論派講師，員工學完無法應用

**Pull (吸引來 Swanky 的力量):**
- TIME Magazine / 國際獎項帶來的可信度
- 制服女孩系列等具代表性的 IP 作品
- 豐富的公開文章與演講紀錄讓潛在客戶「認識」Swanky 已久

**Habit (讓潛在客戶維持現狀的力量):**
- 已有固定配合的攝影師或顧問
- 企業培訓預算有限，傾向大眾化課程平台

**Anxiety (對合作的疑慮):**
- 「我不確定一個人能否同時做好這麼多事」
- 「如何確認是否適合我的產業？」

- 主要：透過 Email（swanky.hsiao@gmail.com）聯繫
