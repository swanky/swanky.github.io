進行中的開放協議實驗 · 2026 重啟

為 NFT 持有者打造的鏈上驗證社交層，正演進成一套「簽名 Feed」開放協議——讓區塊鏈只做它最該做的事：身份與真實性。

觀看 Pitch 影片（2022 原始願景） 聊聊這個項目

它想解決什麼問題？

NFT 市場龐大，但這個社群的「社交基礎設施」其實是斷裂的。

身份無法驗證

PFP 可以被冒用

任何人都能複製一張頭像當作自己的 PFP，沒有機制能證明「你真的持有這個 NFT」。

中心化風險

Discord 被駭損失慘重

光是 Discord 社群遭駭，跨 NFT 社群累積的損失就超過 2,200 萬美元。

單向溝通

公告工具，不是社交平台

Discord、Telegram 本質是群發公告，難以建立真實的「人對人」連結。

社群碎片化

每個項目各自為政

每個 NFT 項目經營各自封閉的頻道，無法跨系列發現志同道合的人。

解法：一層「可驗證」的去中心化社交

GMF 把 NFT 生態最缺的三件事補起來——Verified、Social、Fun。

VERIFIED

鏈上直接驗證

透過 ERC-721 的 balanceOf() 直接在鏈上驗證 NFT 持有，零信任假設、零第三方 API 依賴。

SOCIAL

為持有者打造的社交圖譜

發現與你持有相同系列的「frens」，把鏈上身份連結到真實世界的個人檔案。

FUN

GM 文化變成配對

「GM（Good Morning）」是加密圈的招呼儀式——互相 GM 即配對成功、解鎖聯絡方式。

2026 的樞紐：從「平台」到「開放協議」

最重要的一次認知轉移——區塊鏈不該當內容或支付層，它該當「身份與真實性」層。

於是 GMF 從一個託管式的社交 App，演進為 Signed Feed（簽名 Feed）開放協議：每個身份（就是你的錢包）用私鑰簽署自己發佈的內容；訂閱者執行本地 Agent 把訂閱的 feed 抓回來、驗證簽章、過濾與摘要。內容存在鏈外，鏈只負責證明「這確實是某個身份簽的」。最關鍵的是——這張「信任圖譜」屬於訂閱者本人、可攜帶可匯出，不被任何平台綁架。

VERIFIED

已驗證

簽章回推的地址＝宣稱的作者，內容可信。

MISMATCH

地址不符

簽章成功回推但地址對不上——可能被竄改或盜簽。

MALFORMED

格式損壞

簽章無法回推、或 payload 損壞。

UNSIGNED

未簽名

沒有簽章（Web2／RSS 來源）——永遠不會被偽裝成已驗證。

簽章採用 EIP-191（錢包 personal_sign），對的是內容的 sha256 雜湊而非原始內文——所以內容可以被搬移、鏡像到任何地方，只要雜湊對得上就依然可驗證。原本的「互相 GM 配對」，在新模型裡只是「一則指定給單一對象的 Feed Item」的特例。

技術棧

2026 全新重寫，以現代全端架構與工程紀律打底。

Next.js 16（App Router） TypeScript SIWE（EIP-4361）+ NextAuth 5 wagmi 2 · viem · RainbowKit PostgreSQL 16 · Prisma 6 EIP-191 簽章驗證 ERC-721A 合約 DDD 六邊形架構 BDD · TDD Tailwind CSS 4

附帶一段務實的工程決策：2022 年的舊版程式碼經安全檢視，發現登入未驗證錢包簽章、JWT 存在 localStorage、CORS 全開等結構性缺陷——重建比修補更划算。這也是 GMF 今天改用 SIWE + Next.js 全端架構的原因。
