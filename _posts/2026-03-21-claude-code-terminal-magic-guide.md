## 1. 序幕：擁抱終端機——開啟 AI 協作的新視界

歡迎來到開發者的新紀元！如果你過去對黑底白字的終端機（Terminal）感到畏懼，或是認為那只是高手專屬的冷酷領地，那麼 Claude Code 將徹底翻轉你的認知。

在這裡，終端機不再是一道冰冷的高牆，而是你與 AI 直接對話、共創作品的快捷路徑。Claude Code 不僅僅是一個工具，它是一位具備高度理解能力的**智慧代理人（Agent）**。它能讀取你的意圖、理解你的專案架構，並在轉瞬之間完成複雜的開發任務。

學習這些指令並非為了背誦，而是為了掌握與這位智慧夥伴溝通的「魔法」。當你學會如何精準地調度它，你會發現開發不再是繁瑣的代碼堆砌，而是一場充滿創意的協作。現在，讓我們從掌握時間與空間的魔法開始，踏上這段加速之旅。

## 2. 時空管理術：防止對話污染與後悔藥功能

在開發過程中，對話的純淨度直接影響 AI 的判斷準確性。Claude Code 提供了獨特的指令，讓你在不干擾主線任務的情況下獲取資訊，並賦予你「穿越時空」修正錯誤的能力。

### 並行處理的藝術：/btw

當 Claude 正在執行大型任務（如重構模組）時，你可能突然想詢問一個不相關的小問題。過去，這會中斷 AI 運作並污染對話歷史，導致 AI 跑偏。

> **專家秘訣：並行處理與極致節能**
>
> `/btw` 指令允許你在不污染對話歷史的情況下插入問題。它會開啟一個獨立的平行進程，回答完畢後你可以直接消除該對話。這不僅保持了主線對話的乾淨，更重要的是它複用了當前的提示快取（Prompt Cache），幾乎不會額外消耗 Token，是既高效又經濟的開發習慣。

### 穿越時空的後悔藥：/rewind（雙擊 Esc）

實驗是進步的階梯，但失敗的實驗往往會把代碼弄得一團糟。`/rewind` 是你的守護神，只需雙擊 Esc 即可觸發。

| 回退模式 | 適用情境 |
|---|---|
| 回退代碼與對話 | 當整個實驗方向錯誤，想徹底回到某個時間點重來時 |
| 僅回退對話（保留代碼） | 當代碼修改正確，但想清除冗長討論以釋放上下文空間時 |
| 僅回退代碼（保留對話） | 方案行不通，需撤銷代碼，但想保留 AI 的思考紀錄以換個方向嘗試 |
| 壓縮對話釋放空間 | 當會話過長導致 AI 反應變慢或 Token 快封頂時，從該點開始壓縮優化 |

掌握了這些節奏，你就能大膽地進行各種開發實驗，不再害怕「弄亂代碼」，因為你隨時擁有重來的權力。

## 3. 效能優化：讓每一分錢與每一秒鐘發揮最大價值

專業開發者懂得如何分配資源。透過特定的「隱藏模式」與優化指令，你可以讓 Claude Code 在精確度與速度之間達成完美平衡。

### 混合動力的智慧調度：/model opusplan

這是一個「正兒八經」的隱藏指令，對於追求高品質又想省錢的 Pro 用戶來說是絕對的福音。它啟動了混合動力模式：

- **規劃階段**：自動調用邏輯推理能力最強的 Claude Opus 4.6 來分析複雜架構。
- **執行階段**：自動切換至速度飛快、效能優異的 Claude Sonnet 4.6 撰寫代碼。

這種「先規劃、後執行」的邏輯，能確保複雜任務的精準度，同時幫你省下寶貴的高階模型配額。

### 三位一體的代碼審查：/simplify

比起已經顯得過時的舊指令 `/review`，`/simplify` 更加強大。你可以將它想像成**「三位資深同事同時為你進行 Code Review」**，它會啟動三個平行 Agent，專注於：

1. **代碼復用**：檢查重複邏輯，提煉可重組件。
2. **代碼質量**：移除冗長 Import、優化語法，確保代碼潔淨。
3. **運行效率**：尋找更高效的算法，確保運行效能。

## 4. 開發實驗室：平行分支與自動化循環

在開發過程中，靈活性是效率的關鍵。Claude Code 讓你可以隨時分叉思考路徑，甚至讓 AI 自動執行任務。

- **平行宇宙：/branch（原 /fork）**
  如果 `/rewind` 是「後悔藥」，那 `/branch` 就是「平行宇宙」。當你想針對同一個需求嘗試兩種完全不同的實現路徑時，分叉出一個新會話，讓實驗互不干擾。

- **自動化循環：/loop**
  你可以命令 Claude 定時執行任務（如：`/loop 5m 檢查部署狀態`）。

- **知識沉澱：/export**
  將整段精彩的對話導出為 Markdown 文檔。這對於保存架構決策紀錄，或是將資訊餵給其他 AI 工具協作極具價值。

> **隱藏寶藏：/insights**
>
> 建議每個月跑一次這個指令！它會生成一個 HTML 報告，深度分析你的使用習慣、翻車現場，甚至會針對你的「開發黑歷史」給出改進建議，讓你更了解自己的進步曲線。

## 5. 跨界與捷徑：遙控操作與高手必備快速鍵

最後，我們要打破設備的限制，並掌握那些能讓你操作如行雲流水般的快捷組合。

### 遙控協作：/remote-control（/rc）

想在沙發上或是通勤時進行「Vibe Coding」嗎？這就是你的遠端門票：

1. 在終端機輸入 `/rc`。
2. 系統會生成一個專屬加密 URL。
3. 用手機打開連結，手機即刻變成遙控器，同步操控本地電腦。

這非常安全，因為代碼仍在你電腦運行，手機僅作為遠端窗口。

### 高手必備快捷鍵

| 快捷鍵 | 功能 |
|---|---|
| `Ctrl+V` | 一鍵貼上截圖（Mac 用戶亦使用 Ctrl）。Debug 時直接截圖貼給 Claude，讓它「看圖說話」找 Bug |
| `Ctrl+J`（或 `Option+Enter`） | 換行魔法，輸入多行指令不再誤觸發送 |
| `Ctrl+R` | 快速檢索過往的 Prompt 歷史，重複指令免輸入 |
| `Ctrl+U` | 一鍵清空輸入行，打錯字時的救星 |

在 AI 驅動的時代，工具的更新速度超乎想像。今天所學的指令，不僅是為了提升開發效率，更是為了培養一種「與 AI 共生」的直覺。

身為開發者，最重要的一點是：不要害怕出錯。終端機裡的每一行指令、每一次 `/rewind`，都是你成長的養分。建議你持續關注 Claude Code 的 `CHANGELOG.md`，並對這飛速發展的世界保持好奇。

工具會不斷進化，但你那顆敢於實驗、追求卓越的心，才是這場開發旅程中最強大的動力。祝你 Coding 愉快，享受與 Claude 攜手創造的每一刻！
