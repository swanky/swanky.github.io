「我買了一張 NFT，那張圖到底存在哪裡？是存在區塊鏈裡嗎？」

這是我在課堂上最愛問學生、也最多人答錯的一題。答案會顛覆很多人的直覺——**你買的那張圖，幾乎可以肯定不在區塊鏈上**。

要搞懂這件事，得拆開 NFT 的「技術堆疊」。這是我「[Web3 入門精選]({{ '/education/crypto/web3-essentials/' | relative_url }})」系列裡，最適合搞清楚「NFT 到底是什麼」的一篇。

### 一、先分清楚三種代幣標準

談 NFT 之前，要先認識以太坊上三種最重要的「代幣標準（Token Standard）」。標準就像規格書，規定了一種代幣該有哪些功能、別人該怎麼跟它互動。

| 標準 | 中文 | 性質 | 典型用途 |
|---|---|---|---|
| **ERC-20** | 同質化代幣（FT） | 每一顆都一樣，可互換 | 加密貨幣、治理代幣、穩定幣 |
| **ERC-721** | 非同質化代幣（NFT） | 每一顆都獨一無二 | 數位藝術、頭像、收藏品 |
| **ERC-1155** | 半同質化代幣 | 同一合約可同時管理 FT 與 NFT | 遊戲道具、混合型資產 |

理解它們的關鍵在「同質化」三個字：

- **ERC-20 是同質化的**——你的 1 顆 USDC 跟我的 1 顆 USDC 完全一樣，可以隨意互換，就像鈔票。
- **ERC-721 是非同質化的**——每一顆代幣都有獨一無二的編號（token ID），彼此不能互換，就像每張畫、每張房契都是獨立的。這就是 NFT（Non-Fungible Token）的「Non-Fungible」。
- **ERC-1155 是「半同質化」**——它聰明地讓一份合約能同時管理「可堆疊的同質化道具」（例如遊戲裡的 1000 把鐵劍）與「獨一無二的稀有物品」（例如一把傳說武器），對遊戲與大型生態特別實用。

### 二、NFT 的技術堆疊：圖片其實在鏈外

現在回到開頭的問題。一個 NFT 的完整技術堆疊，是這樣一層層串起來的：

```
智能合約（ERC-721）
   └── tokenURI（一個網址）
          └── metadata.json（描述檔）
                 └── IPFS 上的圖片 / 影片
```

讓我白話拆解：

1. **鏈上的智能合約**只記錄「最關鍵、最不能造假」的事：**這個 token ID 屬於哪個錢包地址**。這就是「所有權」，是 NFT 真正寫在區塊鏈上、永不可竄改的部分。
2. 合約裡有一個函式叫 **`tokenURI`**，它回傳的不是圖片，而是**一個網址**——指向一份描述檔。
3. 這份 **`metadata.json`** 描述檔，記載了這個 NFT 的名稱、屬性、以及最重要的——**圖片的真正存放位置**。
4. 而那張圖片，通常存放在 **IPFS（InterPlanetary File System，星際檔案系統）**——一個去中心化的檔案儲存網路。

所以結論是：**鏈上存的是「所有權證明」，圖片本身存在鏈外（IPFS）**。為什麼要這樣設計？因為區塊鏈儲存空間極其昂貴，把幾 MB 的高解析圖片塞進鏈上是天價且不切實際的。

### 三、那 IPFS 是什麼？為什麼不直接放普通伺服器？

你可能會問：「圖片放鏈外，那跟存在某公司的伺服器有什麼不同？萬一公司倒了圖不就沒了？」

問得好。這正是 **IPFS** 要解決的問題。傳統網址（HTTP）是「**用位置找檔案**」——你連到某台伺服器的某個路徑，伺服器一關，檔案就消失。IPFS 則是「**用內容找檔案**」：它根據檔案的內容算出一個獨一無二的指紋（稱為 CID，內容識別碼），只要全世界任何一個節點還留著這份內容，你就能透過這個指紋把它找回來，**不依賴任何單一公司的伺服器**。

這帶來一個額外的好處：**防竄改**。因為指紋是由內容算出來的，只要圖片被改動一個像素，指紋就會完全不同。所以你的 NFT 描述檔裡記的那個 IPFS 指紋，本身就保證了「你看到的圖，就是當初鑄造時的那張圖」。（不過實務上要真正永久保存，仍需有人持續「釘住（pin）」這份檔案，這是 NFT 長期保存的一個現實課題。）

### 四、從 CryptoKitties 到品牌大舉進場

理解了技術，再看一眼 NFT 的發展里程碑，會更有畫面：

- **2017　CryptoKitties**：第一個引爆主流關注的 NFT，靠著「養貓、配種」的玩法一度塞爆以太坊。
- **CryptoPunks**：一萬個像素頭像，後來成為 NFT 收藏的藍籌標竿。
- **2021　Beeple**：數位藝術家的作品在佳士得（Christie's）以 **6,930 萬美元**成交，把 NFT 推上全球新聞版面。
- **BAYC（無聊猿）**：不只是頭像，而是發展成一整個生態系與社群品牌。

更值得注意的是**傳統品牌的大舉進場**。Nike（透過收購 RTFKT）的 NFT 相關營收一度超過 **1.86 億美元**，Dolce & Gabbana、Gucci、Adidas、Tiffany 也紛紛投入。品牌看上的，是 NFT 提供的兩樣東西：**可驗證的稀缺性**，以及**與鐵粉的直接連結**。

### 五、被低估的設計：創作者版稅

最後談一個我認為 NFT 最有意思、卻最常被忽略的設計——**創作者版稅（Royalty）**。

在傳統世界，一位畫家把畫賣出去之後，這幅畫後續在拍賣會上轉手再多次、漲再多倍，原作者都拿不到一毛錢。但 NFT 可以把「**每次二級市場轉售時，自動抽 X%（常見 10%）回饋給原創作者**」這個規則寫進智能合約裡。

這在概念上是革命性的：**創作者第一次能夠分享到自己作品「長期增值」的果實**，而不只是一次性的售出收入。（必須誠實補充：版稅的「強制執行」在實務上一直有爭議，部分交易市場為了競爭而選擇不強制收取——這也是 NFT 生態仍在演化中的議題。）

### 結語：所有權，才是重點

繞了一圈，我們回到 NFT 的本質。剝掉那些天價拍賣與炒作的喧囂，NFT 真正的技術貢獻只有一件事——**它讓「數位物品的所有權」第一次能被清楚、公開、不可竄改地記錄下來**。圖片可以被無限複製，但「誰擁有那個鏈上唯一的所有權憑證」是無法複製的。

這恰好呼應了我在 [Web3 三時代]({{ '/technical/web3-three-eras/' | relative_url }}) 裡談的核心——**Web3 的靈魂是「擁有」**。而 NFT，就是「擁有」這件事在數位世界裡最具體的一種長相。
