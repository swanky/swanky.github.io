# SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full technical SEO layer to swanky.github.io — analytics, structured data, breadcrumbs, corrected meta tags, and keywords across all 25 posts.

**Architecture:** Jekyll static site on GitHub Pages. All changes are front matter, Liquid template edits, or new `_includes/` files. No server-side logic, no new plugins. Verification is done by building the site (`bundle exec jekyll build`) and grepping `_site/` for rendered output.

**Tech Stack:** Jekyll 4, Liquid templates, Schema.org JSON-LD, HTML meta tags, GA4 gtag.js

**Spec:** `docs/superpowers/specs/2026-03-22-seo-design.md`

## Task 2: Head Template — Meta Tag Fixes

**Files:**
- Modify: `_includes/head.html`

Current `head.html` lines 9, 12, 20 need updating. Four changes in one edit session.

- [ ] **Step 1: Fix og:type to cover layout: article**

Line 9 currently reads:
```html
<meta property="og:type" content="{% if page.layout == 'post' %}article{% else %}website{% endif %}">
```

Replace with:
```html
<meta property="og:type" content="{% if page.layout == 'post' or page.layout == 'article' %}article{% else %}website{% endif %}">
```

- [ ] **Step 2: Fix og:image to use cover_image fallback**

Line 12 currently reads:
```html
<meta property="og:image" content="{{ page.og_image | default: '/assets/img/About_r.jpg' | absolute_url }}">
```

```html
{% if page.og_image %}
<meta property="og:image" content="{{ page.og_image | absolute_url }}">
{% elsif page.cover_image %}
<meta property="og:image" content="{{ page.cover_image | absolute_url }}">

{% endif %}
```

## Task 5: BreadcrumbList Include and Layout Wiring

**Files:**
- Create: `_includes/breadcrumbs-jsonld.html`
- Modify: `_layouts/page.html`
- Modify: `_layouts/home.html`

- [ ] **Step 1: Create _includes/breadcrumbs-jsonld.html**

Create file with this exact content:

```html
{% if page.breadcrumbs %}
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {% for crumb in page.breadcrumbs %}
    {
      "@type": "ListItem",
      "position": {{ forloop.index }},
      "name": {{ crumb.name | jsonify }},
      "item": "{{ crumb.url | absolute_url }}"
    }{% unless forloop.last %},{% endunless %}
    {% endfor %}
  ]
}
</script>
{% endif %}
```

- [ ] **Step 2: Add include to _layouts/page.html**

`_layouts/page.html` currently:

```

---
{% include breadcrumbs-jsonld.html %}

</main><!-- End #main -->
```
