A Monday Story

史旺姬的週一：同一段話，她已經講了五遍

史旺姬（史旺基的原創虛擬角色，在這份教材裡是公司的實習生）在〈AI 入門〉學會了六塊積木。從此每週一早上，她都打開 AI，打同一段話：「幫我整理上週週報：給主管看、一頁以內、三段、待辦做成表格……」（故事為虛構）

  1. 第 1 週

    😊 成果很滿意

    六塊積木都放了，AI 一次就交出主管要的週報。

  2. 第 3 週

    😵 趕時間漏了一句

    忘了講「一頁以內」，AI 寫了三頁。

  3. 第 5 週

    🤷 換人就斷掉

    史旺姬請假，阿哲幫忙代班，完全不知道要交代這些。

交辦說清楚了每次重講，就有機會漏好的交辦只存在一個人的腦袋裡
這個單元要回答

同一件事第五次交代 AI，你還要從頭講嗎？怎麼把一次寫好的交辦，變成下次、和別人都能直接用的指示？

先想 10 秒：你有沒有一段話，已經對 AI 講過三次以上？把它記下來，讀到第五幕就用得上。還不熟六塊積木（角色、任務、背景、限制、格式、範例）的話，先回去看〈{% include ai-learn/chref.html module=basics slug="prompt" anchor="blocks" label="好 Prompt 的 6 塊積木" %}〉。

只記一句同一件事交代第二次之前，先把它寫成可以重複用的樣子。

How to Read

這份教材怎麼看

五幕各回答一個問題，可以照順序讀，也可以挑卡住的那一幕。只有 10 分鐘的話，先看下面的八個誤會，再讀各幕最後的「帶走這幾句」。

五幕，一條主線

先拆穿框架和咒語的迷思，再學官方教的寫法、懂行話，最後做出一份模板。史旺姬和小機器人會陪你走完；插畫裡戴白色笑臉大帽的老師，是史旺基的數位分身。

每個說法都有出處

研究、官方文件和真實事件都附原始連結，可以自己點開核對。示範用的人名、公司與數字是虛構的，會另外標明。

先猜，再看答案

第二、三幕有五題小測驗，題目都是真實的實驗；先選一個，再看研究怎麼說。猜錯不要緊，大多數人第一次都猜錯。

五句可以直接抄

每個原則都附一句可以直接貼進對話框的話；第五幕把它們組成一份模板，附自我檢核。

學完之後，你能做到這五件事：

  1. 1看到新框架不慌，知道怎麼拆
  2. 2用四個原則把要求說清楚
  3. 3判斷「這招超神」靠不靠得住
  4. 4用行話寫出內行的交辦
  5. 5把常做的事寫成模板

閱讀進度、勾選紀錄只存在你這台裝置的瀏覽器裡。

Five Acts

五幕，從迷思走到模板

前三幕把要求「說清楚」：框架怎麼看、官方教什麼、咒語靠不靠得住；後兩幕把它「說內行、說一次」：懂行話，再寫成模板。

The Ladder

從一次交辦，走到可重複的工作指示

這個單元走完前三階：先把一次交辦說清楚，發現自己在重講，就把它寫成模板。第四、五階是之後的事：模板整理成團隊共用的工作手冊，再用真實任務反覆測、反覆改。

只記一句同一件事講到第三次，就是把它寫成可重複工作指示的時候。

Self Check

自我檢核：我真的會了嗎？

不看教材，你能做到這 8 件事嗎？做得到就打勾；不確定就打開參考答案對照，意思對就算過，不用一字不差。說不出來，就回到旁邊標的那一幕重讀。

  1. 回去看 → {% include ai-learn/chref.html module=mod slug="frameworks" anchor="verdict" label="框架是檢查清單" %}

    參考答案
    多數縮寫查不到提出者，也沒有研究證明哪個最好；拆開來看都是同幾塊積木換字母重排。有用的是「把需求拆開來想」：寫完用六塊積木逐塊檢查，缺哪塊補哪塊。

  2. 回去看 → {% include ai-learn/chref.html module=mod slug="principles" anchor="reason" label="原則 1：規則附理由" %}

    參考答案
    例：「不要用英文縮寫，因為讀者是剛加入的新人和長輩。」只給規則，它只會避開你點名的那個字；說了理由，它會自己把沒點名的縮寫也換成白話。

  3. 回去看 → {% include ai-learn/chref.html module=mod slug="principles" anchor="sandwich" label="原則 2：Prompt 三明治" %}

    參考答案
    資料用 <資料>……</資料> 這類標籤框起來放上面，要它做的事寫在最後一段。各家建議略有不同（OpenAI 建議指示放頭尾各一次），但「資料和指示分開」是共同點。

  4. 回去看 → {% include ai-learn/chref.html module=mod slug="principles" anchor="done" label="原則 3：先定義怎樣算完成" %}

    參考答案
    例（延期通知信）：300 字以內；第一段就說出新的交期；結尾留聯絡窗口與電話。每一條都能回答「有／沒有」，不能打勾的形容詞（好一點、專業一點）不算。

  5. 回去看 → {% include ai-learn/chref.html module=mod slug="principles" anchor="askme" label="原則 4：讓 AI 先反問你" %}

    參考答案
    例：「我想做年終聚餐的企劃。在你動手寫之前，請一題一題問我，直到我們對這件事有共同理解；每題附上你建議的答案，每輪最多 3 題。」重點：先別動手、附建議答案、設上限。

  6. 回去看 → {% include ai-learn/chref.html module=mod slug="magic-words" anchor="three-questions" label="先問三個問題" %}

    參考答案
    ① 它量的是什麼？（字數變長不等於答對）② 樣本有多少？（5 次很容易碰運氣）③ 真正有用的是哪幾句？（拿掉話術，常常只剩「自己驗證」「不要多改」這種本來就該講清楚的要求）

  7. 回去看 → {% include ai-learn/chref.html module=mod slug="domain" anchor="checklist" label="各領域的完成條件" %}

    參考答案
    例（寫 email）：BLUF、主旨標籤、收件人與副本的角色；完成條件：「只讀主旨和第一段，就知道要誰在何時前做什麼。」

  8. 回去看 → {% include ai-learn/chref.html module=mod slug="template" anchor="template" label="可重複 Prompt 模板" %}

    參考答案
    合格標準：① 有挖空的【變數】格 ② 每條規則旁有一句「因為」③ 最後有可以打勾的完成條件。用兩份不同的資料各跑一次，兩次都沒改到的段落，就是可以一直重複用的工作指示。
