# 職場塔羅・牌義撰寫規格（共用）

你要為一個「職場塔羅」線上工具撰寫繁體中文(zh-TW)牌義文案。**這不是占卜算命，是把塔羅當「職場反思的鏡子」**——給工程師與技術主管，把牌面象徵翻成職場語言，幫人把卡住的處境想清楚、看見下一步。

## 語氣
像一個值得信賴的前輩在跟你聊天：白話、溫暖、有畫面感，**不神秘兮兮、不通靈腔、不掉書袋**。塔羅術語出現時一定附白話解釋。全程 zh-TW（繁體中文、台灣用語）。

## 七條硬性安全守則（每張牌都要通過）
1. **不預測具體事件**：只談「你此刻可以怎麼看、怎麼做」。禁止「你會升遷／會被裁／這專案會成功或失敗」這類對未來具體事件的斷言。
2. **不恐嚇**：全程禁用「厄運、災難、注定、命中註定、報應、劫數」。負面牌（高塔、死神、惡魔、寶劍十、寶劍三等）一律寫成「轉變／卸下／看清結構／誠實面對」的成長語言，不寫成警告或預兆。
3. **不宿命、留主動權**：action 收斂到「一個一週內可主動做的明確行動」，語氣是邀請不是命令；symbol 不暗示結果已定。
4. **逆位＝另一個切入角度**：reversed 欄位不寫負面、不寫壞兆頭，只是「同一個畫面換個角度看」。
5. **必要時轉介**：涉及情緒／健康／關係創傷的牌（寶劍三、寶劍九、月亮、寶劍十等）的 work 要自然帶一句溫和提醒：若這觸到的是真實的痛，找信任的人或專業資源聊聊，比抽牌更要緊。
6. **職場語言**：work 對應職場面向（專案壓力／學習成長／職涯方向／團隊互動／工作與生活的取捨），讓人覺得「這張牌好像在說我的狀況」。
7. **全原創**：用你自己的措辭，**絕不抄任何塔羅書或網站的牌義文字**；可借用公認的牌面意象（這是公共知識），但描述與職場詮釋必須原創。

## 每張牌的欄位（對應職場塔羅四段結構）
- `symbol`（牌面象徵）：白話描述核心意象與象徵，2–4 句，帶出它在大牌／小牌體系的位置感。約 60–110 字。
- `work`（職場連結）：把象徵對應到職場處境，2–4 句。約 60–110 字。
- `reflect`（反思問題）：**2–3 個**開放式問題，可在一對一談話裡直接問出口。字串陣列，**不要自己加引號**（介面會加）。
- `action`（行動建議）：**1 個**一週內可完成的具體行動（不是「多溝通」，而是「這週找 PM 約 30 分鐘，聊 scope 優先順序」）。
- `reversed`（逆位視角）：1–2 句，這張牌「反過來出現」時的另一個切入角度，不負面。

## 黃金範例（請模仿這個水準與語氣，**不要照抄文字**）

**星星 The Star**
- symbol：星星是大牌裡的喘息與補給站，高塔的劇變過後，天空終於安靜下來。畫面是一個人在水邊，把水倒回大地與池子——一種「先把自己重新灌滿」的溫柔。它不轟轟烈烈，是低調的希望：你還有底氣，只是需要慢下來認領它。
- work：如果你最近在想職涯方向，星星說的不是「快做決定」，而是「先確認你還相信什麼」。在忙到麻木之後，你心裡那個還會發亮的方向，可能被你自己忽略了很久。
- reflect：["撇開現實限制，現在還會讓你眼睛發亮的工作畫面，是什麼樣子？", "最近一次覺得自己被重新灌滿、而不是被掏空，是什麼時候、在做什麼？", "如果接下來三個月只能修復一件讓你耗損的事，你會選哪一件？"]
- action：這週空出一段不被打擾的 30 分鐘，寫下三件「做了會讓你恢復電力」的小事，並把其中一件排進下週的行事曆。
- reversed：逆位的星星，邀請你檢查一下：是不是把希望都寄託在「外在條件到齊」，卻忘了你此刻就能給自己一點補給？把焦點從「等環境變好」挪回「我現在能做的一小步」。

**高塔 The Tower**（示範負面牌如何寫成成長語言、不恐嚇）
- symbol：高塔是大牌裡最有戲劇張力的一張：一道閃電打在高塔上，原本看似穩固的結構崩落。第一眼會嚇到，但塔真正在講的是——那座塔本來就蓋在不太對的地基上，這道閃電只是讓你終於看見、也終於能重蓋。它拆的是假的穩，不是你的人生。
- work：如果專案裡有個你一直繞著走、不敢承認的問題（架構、範圍、還是某段關係），塔說的是：與其等它哪天自己垮，不如趁現在主動把它攤開來談。早一點痛，比晚一點塌好。
- reflect：["有沒有一件你其實早就知道不對、卻一直沒去碰的事？是什麼讓你還沒動它？", "如果這個鬆動是來幫你的，它想讓你看清楚的是什麼？", "假設它非變不可，你會希望由你主動拆，還是等它自己塌？"]
- action：這週挑那件你「一直繞著走」的事，找一個能談的對象（主管、PM、或信任的同事）約 30 分鐘，只做一件事：把問題誠實講出來、不急著解決。
- reversed：逆位的高塔，往往是崩塌前的悶——你已經感覺到不對，但還在拖。它邀請你把「假裝沒事」的力氣，省下來面對那個你心知肚明的小裂縫。

**權杖三 Three of Wands**（小牌示範）
- symbol：權杖三的畫面是一個人站在高處，望向遠方的海，三根權杖已經立穩。前一張還在猶豫要不要出發，到了三，船已經放出去了——這是「決定做了、開始等回音」的階段，關鍵字是展望與等待。
- work：職涯上，這張牌常出現在你已經播了種、正在等發芽的時候：投了履歷、開了對話、起了一個側專案。它說，該做的開場你已經做了，現在是把視線放遠、別盯著腳邊焦慮的時候。
- reflect：["你最近放出去、正在等回音的『那條船』是什麼？", "如果把視線從腳邊抬起來望向三個月後，你最希望看到什麼正在靠岸？"]
- action：這週列出你「已經發出去、正在等結果」的 1–2 件事，為其中一件寫下「如果有回音，我下一步要做什麼」，先把接球的準備做好。
- reversed：逆位的權杖三，可能是你已經出手、卻忍不住一直回頭檢查的焦慮。它邀請你把那份能量，從「盯著已寄出的信」轉到「準備好下一步」。

## 輸出格式（極重要）
直接用 **Write 工具**把檔案寫到指定路徑。檔案內容格式如下（**第一行就是 export、不要 markdown 圍欄、不要任何解說文字**）：

```
export const VARNAME = {
  'card-id': {
    symbol: '……',
    work: '……',
    reflect: ['……', '……'],
    action: '……',
    reversed: '……',
  },
  // …每一個指定的 id 都要有，順序照給定清單
};
```

字串一律用**單引號**。**字串內絕對不要出現未跳脫的半形單引號 `'`**——需要引號時改用中文引號「」。可用全形標點。每個物件最後一個屬性後可留逗號（trailing comma 合法）。寫完後簡短回報你完成了幾張牌、檔案路徑。
