# 職場塔羅 → 多領域擴充・牌義「視角」撰寫規格（共用）

工具從「只談職場」擴充成**通用反思工具**，但**骨架不變：塔羅是反思的鏡子，不是占卜**。
現在每張牌除了既有的「職場」解讀，要再加三個領域的視角：**感情關係 love／生活與自我 life／財務與重大決策 money**。

## 你要做的事
為指定的每張牌，寫出 **love / life / money 三個領域**各一組：
- `connect`（對照你的處境）：把這張牌的象徵，對應到該領域的處境，2–4 句、約 60–110 字。
- `reflect`（反思問題）：2–3 個開放式問題，可直接問出口。字串陣列，**不要自己加引號**。
- `action`（一個一週內可做的小行動）：具體、可執行、語氣是邀請。

**不要重寫** `symbol`（牌面象徵）和 `reversed`（逆位視角）——那兩個是跨領域共用、已經寫好了。
**務必先用 Read 讀取該牌組既有的 `assets/js/tarot/tarot-text-{你的組}.js`**，看每張牌的 `symbol` 與既有的職場 `work`，讓你的 love/life/money 視角**和這張牌已經確立的意象一致**（同一張牌、不同人生切面，不是換一張牌）。

## 通用語氣與七條安全守則（全領域適用）
- 像值得信賴的前輩聊天：白話、溫暖、有畫面感，不神秘兮兮、不神棍腔。全程 zh-TW。
- ①不預測具體事件　②不恐嚇（禁用「厄運／災難／注定／命中註定／報應／劫數」，負面牌寫成轉變／看清的成長語言）　③不宿命、action 收斂成一個一週內可主動做的事　④逆位＝換角度（但逆位這次不用你寫）　⑤必要時溫和轉介專業　⑥對應該領域的真實處境　⑦全原創、不抄任何塔羅書。

## 各領域的紅線（非常重要，違反就破壞整個工具的定位）

### 感情關係 love
- **絕對不預測對方**：不算「他愛不愛我／會不會回來／會不會在一起／何時脫單／是不是真命天子」。塔羅在這裡照的是**你自己**，不是讀心術。
- 焦點放在：你在這段關係裡真正的需求、你的模式與慣性、你的界線、你一直逃避的那個對話、你能為自己做的選擇。
- 對象涵蓋伴侶、曖昧、單身、家人、朋友等各種關係，不要預設一定是戀愛。
- 若牌觸到關係創傷、被控制、暴力或嚴重痛苦：`connect` 要自然帶一句——這超出一張牌能幫的範圍，請找信任的人或專業資源，你的安全與感受優先。

### 生活與自我 life
- 自我探索、習慣、生活節奏、方向感、內在狀態、和自己的關係。
- 不預測人生大事。涉及持續低落、焦慮、身心耗損時，`connect` 帶一句溫和提醒：若這是持續的狀態，找信任的人或專業心理資源聊聊，比抽牌更要緊。

### 財務與重大決策 money
- **這不是投資理財建議**：絕不暗示會賺會賠、不報明牌、不建議買賣任何標的、不預測市場或漲跌。
- 焦點放在：你與金錢的關係、你的風險承受度、價值排序、做這個決定前你還沒想清楚什麼、你在用錢逃避或證明什麼。
- 重大財務決策，`connect` 可提醒：數字面的部分，找專業（會計師／財務顧問）會比一張牌可靠。

## 輸出格式（極重要）
用 **Write 工具**寫到指定檔案，內容如下（**第一行就是 export、無 markdown 圍欄、無解說**）：

```
export const GROUP_LENS = {
  love: {
    'card-id': { connect: '……', reflect: ['……', '……'], action: '……' },
    // …你負責的每一個 id
  },
  life: {
    'card-id': { connect: '……', reflect: ['……'], action: '……' },
    // …同一批 id
  },
  money: {
    'card-id': { connect: '……', reflect: ['……'], action: '……' },
    // …同一批 id
  },
};
```

三個領域（love/life/money）都要**涵蓋你負責的全部 id**。字串一律單引號；字串內不要出現未跳脫的半形單引號（用「」）；trailing comma 合法。寫完回報三個領域各完成幾張、檔案路徑。
