0{{ sec_n }} · House Rules

這區的四個規矩。

  1. 他人作品只放小圖，當作評論用的引用。每張圖都標明作者、作品、館藏與版權，並連到原作所在的美術館或官方頁面，想看清楚請點過去。
  2. 事實附出處，看法標清楚。每一篇發表前都先核對美術館、基金會與出版社的公開資料；哪些是事實、哪些是我的看法，分開寫。
  3. 說法不一致的，並列不裁定。生年、版本、年份有不同說法時，照實並列；查不到可靠來源的，就不寫。
  4. 權利人想移除，來信就撤。權利人若希望移除他人作品的小圖，請來信，我當天撤圖。
