Agentic Engineering 系列

把 AI 當「高級實習生」帶領，用軟體工程紀律交付

在公司推 Claude Code 的這段時間，我觀察到一個違反直覺的現象：越懂軟體工程、越有專案管理底子的人，越能把 AI 用出價值。AI 沒有把所有人拉到同一條起跑線，它放大了一個人原本怎麼思考、怎麼拆解、怎麼判斷品質的差異。

這個系列就是這套方法的完整記錄——從心法（為什麼建造者勝過衡量者）、引導法（ORID、SDD 規格驅動開發），到實戰工作流（Claude Code 的治理、設計、最佳實踐）。不是工具教學的集合，而是一套「慢即是快」的交付紀律。

需要把這套方法帶進你的團隊？企業內訓 與 導入顧問 歡迎洽詢。
